# data — ファイル一覧と読み方

すべて UTF-8（BOM付き）・CRLF の CSV です。Excel でそのまま開けます。

## corpus.csv — 評価コーパス構成表（141行）

測定に用いた評価コーパスの全件目録です。

| 列 | 内容 |
|---|---|
| `file_id` | コーパス内のファイルID。A=課題の正解になりうる主要ファイル、D=ノイズ（週報・請求書・アジェンダ等の定型文書）、X=旧版/重複、G=画像（図面・現場写真）、E=未調達の外部素材枠 |
| `種別` | ファイル形式 |
| `パス` | コーパス内の配置パス |
| `名前乖離` | ファイル名が内容を表していないものを「あり」とした。138件中54件（39%） |
| `旧版/重複` | 同一内容の旧版・コピーであるもの |
| `内容の要点（ゴールド記述）` | **判定の基準文書。** コーパス生成と同時に凍結しており、AI出力を見たあとに書き換えていない |
| `備考` | ノイズ指定など |

E001〜E003 は長尺PDF・動画の調達枠であり、**本測定では未調達のため対象外**です。したがって測定対象は138件です。

## tasks.csv — 課題定義（50行）

| 列 | 内容 |
|---|---|
| `task_id` | 課題ID |
| `測定対象` | 「対象」の35問が本測定の対象。**T026〜T040の15問は動画コーパスが未調達のため「範囲外」**であり、測定していない |
| `課題タイプ` | 内容手がかり／ページ到達／属性手がかり／否定・不在確認 |
| `質問文` | 実際に入力した文。**測定前に凍結し、測定中の変更・言い換え・追加を禁止した** |
| `正解ファイルID` | 正解。複数正解はセミコロン区切り |
| `正解が存在しない課題か` | 「はい」の5問（T046〜T050）は、「存在しない」と応答することが正解 |
| `作成者` | 起案の担当。**課題文の起案にはAIを用いている** |
| `独立検証者` `検証結果` | **空欄である。第三者による正解の独立検証は行っていない**（限界として本リポジトリのREADMEに記載） |

## results_by_task.csv — 課題別の測定結果（35行）

35課題それぞれについて、6条件の結果を記録しています。列は `条件_指標` の形式です。

| 条件 | 内容 |
|---|---|
| `A_NFC` / `A_NFD` | ファイル名検索（ベースライン）。NFC=通常のIME入力、NFD=結合文字列。**製品のキーワード検索がUnicode正規化を行わないため、濁点を含む語で結果が分かれる。比較には条件Aに有利なNFDを用いた** |
| `C1` | メタデータ検索（AIタグによる絞り込み） |
| `C2` | 会話型AI検索 |
| `C3_NFC` / `C3_NFD` | AI構造検索 |

| 指標 | 内容 |
|---|---|
| `Top1` | 正解が1位に出たか（1/0） |
| `R@10` | 上位10件に含まれた正解の割合 |
| `MRR` | 正解の最良順位の逆数 |
| `ゼロ件` | 結果が1件も返らなかったか（1/0）。**「存在しない」を意味しない** |
| `圏外` | 上位10件に正解が1件も無かったか（1/0） |
| `上位10件` | 実際に返ってきたファイルIDの並び。`f`で始まるIDは、検索母集団に含まれるコーパス外のファイル |

不在確認課題（T046〜T050）は正解件数0のため、順位指標は空欄です。`上位10件` に何かが入っている行が誤検出にあたります。

条件Aの発行方法は、質問文から機械的に抽出した全キーワードを1語ずつ個別に検索し、**最も良かった順位を採用する上界**です。現実の利用者はこれより不利になります。

## quality_claims.csv — AI概要の言明判定（96行）

無作為抽出した30件のAI生成概要を言明単位に分解し、凍結済みのゴールド記述とファイル本文に照らして判定した全件です。

| 判定 | 内容 | 件数 |
|---|---|---|
| `正` | 本文またはゴールド記述に支持される | 90 |
| `誤` | 本文と矛盾する | **0** |
| `未確認` | 本文に根拠がないが矛盾もしない | 6 |

事実誤り率 = 誤 ÷（正＋誤＋未確認）= **0.0%**。「未確認」をすべて誤りとして数え直したい場合は 6÷96 = 6.3% です。判定根拠を全件付けてあるので、別の基準での再計算ができます。

**未確認6件のうち4件は画像ファイルに集中しています。** 画像の用途を推測した記述（「報告書のサンプル画像である」等）が該当します。

## quality_tags.csv — AIタグの適合判定（167行）

同じ30件に付与された全タグの判定です。

| 判定 | 内容 | 件数 |
|---|---|---|
| `TP` | そのファイルの内容を指している | 164 |
| `FP` | 指していない | 3 |

タグ適合率 **98.2%**（164/167）。

`ゴールド記述内に文字列出現` は、そのタグがゴールド記述に部分文字列として現れるかを機械判定した値です（1/0）。全体で 28.1%（47/167）。**適合率98.2%との差を製品の性能差として読まないでください。** ゴールド記述は要点だけを短く書いた文であり、内容として正しいタグでも同じ表記が現れないだけです。判定者の裁量がゼロである下界として併記しています。

再現率とF1は報告していません。正解タグ集合が事前登録されておらず、AIタグを全件見たあとに作る正解集合は検証不能なためです。

## quality_descriptive_stats.csv — 全138件の記述統計

コーパス138件全件について、生成された概要とタグの機械的な集計です。判定は含みません。

| 列 | 内容 |
|---|---|
| `drive_id` | 製品側のコンテンツID |
| `概要文字数` | 平均75.2字（最小27・最大145） |
| `タグ数` | 平均5.61個 |
| `entities数` `persons数` `locations数` | 固有表現抽出の件数 |
| `概要に数字あり` | 1/0。**0の行が56件（40.6%）ある。** 金額・日付・件数など、ファイルを一意に特定しやすい情報が概要に現れていない |
| `タグ集合` | パイプ区切り。**この列が他の行と完全一致するファイルが26件（18.8%）ある。** 最大の群はD014〜D018の5件で、AIタグだけでは相互に区別できない |
| `概要` | 生成された概要の全文 |

週報24件は、部署名を除いたタグ集合の異なり数が**4通りしかありません**。24件の週報を、AIメタデータで4通りにしか区別できないということです。

**正確であることと、見分けられることは別の性質です。** このファイルは、その根拠を確認するためのものです。
